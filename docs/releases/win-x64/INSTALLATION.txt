INSTALL
Run the installer as the current user. The normal per-user app is:
  %LOCALAPPDATA%\Chromium\Application\chrome.exe
Launch Chromium normally. The installed browser is x64; fresh verification ran
on the standard Windows 2025 hosted image with its default sandbox enabled.

Do not replace an existing standalone Chromium installation. Google Chrome has
separate app/profile paths and should remain untouched. Do not point Chromium
at Google Chrome's profile or copy Chrome's profile into it. If needed, choose
an empty dedicated profile directory through --user-data-dir. Native always-
active behavior needs no flags. Choose this app as the default only if desired.

The installer has no Windows Authenticode publisher certificate. A checksum
match establishes agreement with the release manifest, not publisher trust.
Use normal Windows approval UI; do not disable system protections. Browser-
download security prompts were not exercised by the hosted command-line install.

EXTENSIONS AND UPDATES
Use normal Chrome Web Store Add and permission prompts. Fresh per-user delivery
passed all 20 phases for uBlock Origin Lite 2026.1026.1812: normal installation,
audited source/worker execution, restart persistence, ordinary update check,
normal native removal and persisted registration absence, and owned-process
cleanup. no_update does not prove a newer-version upgrade. Removed-extension
identifier metadata can remain without a registered or running extension.

There is no automatic project browser updater. Install a newly built and verified
package to update. Chromium branding, restricted Google services, account sync
and DRM differ from official Chrome. Always-active behavior does not prevent
OS sleep, freezing or tab discard.

Use Windows Installed apps to uninstall Chromium if desired. Preserve Google
Chrome and any profiles you intend to keep. The repository verification.json
and visual-review.json link exact source/build/delivery evidence; original CI
reports remain unchanged. macOS Apple Silicon has its own package and records.
