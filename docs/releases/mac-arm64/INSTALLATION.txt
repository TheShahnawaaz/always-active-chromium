INSTALL
Extract the ZIP with Archive Utility. Move the complete Chromium.app into
Applications, optionally inside a new Always Active Chromium folder. Do not
replace Google Chrome or an existing standalone Chromium app/profile. Open the
app normally. This is arm64 for Apple Silicon, not an Intel Mac package.
The bundle declares macOS 13.0 as its minimum; runtime verification ran on
the standard macOS 26 Apple Silicon runner.

The app is ad-hoc signed, without Apple Developer ID or notarization. macOS
may require ordinary per-app approval for a downloaded app. Browser-download
quarantine/first-launch approval was not exercised by hosted ZIP extraction.
Do not disable Gatekeeper or strip quarantine as an installation step.
No accessibility or recording permission is needed for native always-active use.

Google Chrome's app and profile remain separate. If another standalone Chromium
is present, choose a separate app folder and a fresh dedicated --user-data-dir.
For an app inside /Applications/Always Active Chromium, one explicit launch is:
  open -n "/Applications/Always Active Chromium/Chromium.app" --args --user-data-dir="$HOME/Library/Application Support/Always Active Chromium"
Never point this browser at Google Chrome's profile directory.
